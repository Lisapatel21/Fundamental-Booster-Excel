# 📊 Fundamental Booster – Excel Project

> A hands-on project demonstrating fundamental Microsoft Excel skills and practical spreadsheet data management.

---

## 📖 Introduction

**Fundamental Booster** is an Excel project created to strengthen core spreadsheet skills through practical application. It shows how Excel can be used to organize data, perform calculations, apply formulas, and build a solid foundation for data analysis.

By working through real spreadsheet tasks, the project builds confidence in handling data accurately and efficiently, and reinforces the essential techniques every Excel user needs.

## 📋 Project Data & Tables

### 🗂️ Worksheets in the Spreadsheet

| # | Worksheet | Purpose |
|---|-----------|---------|
| 1 | **Project Instructions** | Lists the topics, main tasks, deliverable, and essential tasks for the project. |
| 2 | **Students Grade** | Student data used for grade classification, counting, and filtering tasks. |
| 3 | **Sales Data** | Sales data used for lookup, summing, and discount tasks. |
| 4 | **Employee Data** | Employee data used for salary lookup and date-of-joining analysis. |

### 📘 Topics Covered

| # | Topic |
|---|-------|
| 1 | Relative & Absolute References, Formatting, Data Input |
| 2 | IF Formulas, Nested IFs, IF with AND/OR |
| 3 | COUNTIFS, SUMIFS, AVERAGEIFS |
| 4 | Lookup Functions (VLOOKUP, XLOOKUP, XMATCH) |
| 5 | INDEX/MATCH for dynamic searches |
| 6 | TEXT Functions for string manipulations |
| 7 | INDIRECT and OFFSET for dynamic references |
| 8 | Date/Time, Math Functions, FILTER function |

### 🎯 Main Tasks

| # | Task |
|---|------|
| 1 | Apply IF formulas to classify student grades. |
| 2 | Use COUNTIFS to count students scoring above 60. |
| 3 | Use VLOOKUP to find a product price from sales data. |
| 4 | Apply XLOOKUP to fetch employee salaries dynamically. |
| 5 | Format and analyze date of joining in Employee data. |
| 6 | Use FILTER function to extract students with grades above 80. |

**Deliverable:** Complete the given worksheets by applying the required formulas in the respective sheets.

### ✅ Essential Tasks

| Topic | Task |
|-------|------|
| **Relative & Absolute Cell References, Formatting, and Data Input** | Enter and format data (bold, italic, currency, date, custom formats). |
| | Use absolute (`$A$1`) and relative (`A1`) references in formulas. |
| **IF Formula & Nested IF Formulas** | Classify students' grades based on their scores. |
| | Compute discounts for sales based on price thresholds. |
| **IF with AND/OR** | Identify students who scored above 80 in both Math & Science using `IF(AND(...))`. |
| | Determine whether a product is eligible for discount using `IF(OR(...))`. |
| **COUNTIFS, SUMIFS, AVERAGEIFS** | Count the number of students who scored above 50 in Math. |
| | Sum total sales for a specific region and product. |
| | Calculate the average score for students who scored above 60. |
| **VLOOKUP** | Fetch student names based on ID from a separate dataset. |
| | Retrieve product prices based on product codes. |
| **INDEX and MATCH** | Find sales values for a specific salesperson in a specific month. |
| | Look up employee details dynamically without column restrictions. |
| **TEXT Functions** | Extract the first name from full names using `LEFT` and `FIND`. |
| | Convert names to uppercase/lowercase using `UPPER()` and `LOWER()`. |
| **XLOOKUP** | Search for salesperson performance based on flexible search criteria. |
| | Find employee salaries without worrying about sorted data. |
| **XMATCH** | Find the position of a product in a sales list. |
| **INDIRECT** | Dynamically reference a cell range using `INDIRECT`. |
| **OFFSET** | Create dynamic ranges for sales trends. |
| **Date and Time Functions** | Calculate age from date of birth. |
| | Find the difference in days between two dates. |
| **Math Functions** | Use `ROUND()`, `CEILING()`, and `FLOOR()` for financial calculations. |
| **FILTER Function** | Extract a list of top-performing students based on scores. |
